# UR-20261011-016 — Deploy-Gate Corrections

**Identity:** UR-20261011-016 · **Version:** 1.0 (Template v1.0, filled instance) ·

**Basis:** the deployment-diagnosis report (11/10/2026) — the `ae2a6d3` deploy was **SKIPPED**, so
production still ran `8355ba4`, and the live logs showed a deprecated `ephemeral` option. This record
closes the three causes.

---

## 1. Summary

The `feature/dev` push `ae2a6d3` did not reach production: Railway's `checkSuites` gate held it
because two GitHub checks failed. The diagnosis found:

1. **The `Gates (D-8.4)` job failed at Gate 3 — format.** `prettier --check` rejected
   `apps/main/tests/unit/env-schema.test.ts` (a test added by `UR-20261011-014`). Every earlier gate
   passed (root typecheck, app typecheck, lint, lint:modules).
2. **The `Documentation gates` job failed.** `check-code-reconciliation.mjs` — whose freshness
   assertion was added by `UR-20261011-012` — exited 1 because the `docs-gates` workflow checks out
   with the **default shallow clone** (`fetch-depth: 1`), so the parent commit `8355ba4` is absent.
3. **The live logs showed the deprecated `ephemeral` option** — the `UR-20261011-013` c6 ephemeral
   Info fix registered `ack: 'ephemeral'`, which calls `deferReply({ ephemeral: true })`, deprecated
   in discord.js 14 in favour of `flags: MessageFlags.Ephemeral`.

---

## 2. Fixes

- **R1 — format (Gate 3).** `tests/unit/env-schema.test.ts` is Prettier-clean. (The whole app now
  passes `prettier --check`.)
- **R2 — docs-gate freshness (Documentation gates).** `check-code-reconciliation.mjs` now treats an
  **absent** `verified_commit` as a **warning**, not a failure (a shallow checkout cannot verify
  freshness), and fails **only** when the commit resolves but is **not an ancestor of HEAD**. The
  `Gates` job, which uses `fetch-depth: 0`, still gets the full ancestor check.
- **R3 — `ephemeral` deprecation.** Every `deferReply({ ephemeral: … })` is replaced by the supported
  form: `interaction-registry.ts` (the `ack: 'ephemeral'` path), `middleware/built-in/defer.ts`, and
  `bootstrap.ts` (the component-acknowledge path). The structural `deferReply` types now carry
  `flags?: number | bigint`. `exactOptionalPropertyTypes` forbids `flags: undefined`, so the defer
  middleware omits the option rather than passing `undefined`.
