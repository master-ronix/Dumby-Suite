## 1. Summary

The normative artefact `spec/reference/appendix-implementation-status-audit-register.md` contains
**45 empty ATX headings** (bare `####` lines with no text). In each case the intended section title
was demoted into the following blockquote. This request restores the titles as headings and adds a
gate rule preventing empty headings in `spec/**`.

## 2. Business / engineering justification

The file is `kind: spec`, `status: normative`. Empty headings are malformed Markdown: they render
as blank heading lines, they contribute no heading text (so no anchor), and they make the document's
structure ambiguous — a reader cannot tell whether the following blockquote is a section body, a
quoted source, or a title. Because the demoted titles are the *only* record of what each entry is
about, the defect degrades the appendix's navigability and its value as a status register. No gate
detects empty headings today.

## 3. Scope & impact

- **In scope:** `spec/reference/appendix-implementation-status-audit-register.md`; a new
  empty-heading rule in the gate suite.
- **Out of scope:** the content of the entries (only their heading lines change).
- **Audiences affected:** engineers reading the implementation-status register; the gate suite.

## 4. Current state (evidence)

- `grep -cE '^#{1,6}\s*$' spec/reference/appendix-implementation-status-audit-register.md` → **45**,
  all `####`.
- Pattern: a bare `####` is followed by a blockquote whose first line is the real title, e.g.
  `> ### 3.2.1 Port Mapping: Docker Compose vs Kubernetes`.
- Contrast: sibling entries already carry titles on the heading line, e.g.
  `#### [From §3 (Engineering Principles (P1–P14))] Standalone `grants` DB table + migration`.
  Finding DA-4.

## 5. Proposed change

1. For each of the 45 occurrences, promote the demoted title from the following blockquote to the
   heading line and drop the empty `####` (preserve the blockquote body below it).
2. Add a gate rule: no empty ATX heading in `spec/**` (and optionally `blueprint/**`,
   `documentation/**`). Implement as a small check or a rule in `check-section-order.mjs`.
3. Re-run `check-anchors` / `check-coverage` to confirm the restored headings resolve.

## 6. Risks & mitigations

| Risk | Likelihood | Mitigation |
|---|---|---|
| Promoting headings shifts anchors referenced elsewhere | Medium | Re-run `check-anchors` / `check-anchor-paths`; update the ledger if a heading is newly covered |
| A blockquote was intentionally a quotation, not a title | Low | Review each of the 45 against its `[From §…]` context before promoting |
| New rule flags legitimate blank headings elsewhere | Low | Scope the rule to `spec/**`; run the suite to confirm |

## 7. Rollback / reversal plan

Revert the file and the gate rule; the appendix returns to its prior state. No other artefact
depends on the empty headings.
