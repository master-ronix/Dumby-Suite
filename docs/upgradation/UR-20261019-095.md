## 1. Summary

`manifest.json` declares three generated artefacts — `_generated/index.md`, `_generated/tree.md`,
and `status/compliance.json`. The gate added to stop a generated artefact rotting checks **only**
`_generated/tree.md`. `_generated/index.md` is therefore declared generated but ungated, and it is
already incomplete. This request closes the DR-1 remediation by either gating `index.md` for
completeness or, if it is a curated index, removing it from the `generated[]` list.

## 2. Business / engineering justification

DR-1 (UR-20261018-092) found generated artefacts stale and ungated; its fix gated `tree.md` and
left `index.md` — which DR-1 explicitly called "likewise partial" — unguarded. An artefact declared
`generated` in the manifest but checked by nothing can rot silently, which is precisely the failure
DR-1 was raised to end. `index.md` already demonstrates the rot: it omits `deploy/`, `_inbox/`,
`_meta/`, `scripts/`, and `_generated/` itself.

## 3. Scope & impact

- **In scope:** `scripts/docs/check-generated.mjs`, `_generated/index.md`, `manifest.json` (`generated[]`).
- **Out of scope:** `tree.md` (already gated) and `status/compliance.json` (gated by `check-compliance`).
- **Audiences affected:** the gate suite; readers who navigate the corpus by its generated index.

## 4. Current state (evidence)

- `manifest.json` → `"generated": ["_generated/index.md", "_generated/tree.md", "status/compliance.json"]`.
- `check-generated.mjs` reads only `_generated/tree.md`.
- `_generated/index.md` lists 17 rows and omits `deploy/`, `_inbox/`, `_meta/`, `scripts/`,
  `_generated/`; its "Assets" row omits `inbox`. Finding DA-2.

## 5. Proposed change

Choose one, and state which:

- **(A) Gate it.** Extend `check-generated.mjs` to assert that `_generated/index.md` contains a row
  for every `manifest.documents` entry, every `manifest.assets` key, `contracts/`, `adr/`, `status/`,
  and `archive/`; fail on any omission. Regenerate `index.md` to pass.
- **(B) Declassify it.** Remove `_generated/index.md` from `manifest.generated[]` and reclassify it
  as a curated, hand-maintained index (then it needs no freshness gate, but should say so).

Recommended: **(A)** — the file is titled "Corpus index (generated)" and lives in `_generated/`.

## 6. Risks & mitigations

| Risk | Likelihood | Mitigation |
|---|---|---|
| New gate fails until `index.md` is regenerated | High | Ship the regenerated `index.md` in the same change-set |
| Over-broad coverage rule catches intentional curation | Medium | Gate against the manifest sets (the single source), not an ad-hoc list |
| Duplicate logic with `check-manifest` | Low | Reuse the manifest read; keep the gate small |

## 7. Rollback / reversal plan

Revert the gate change and the regenerated `index.md`; the file returns to ungated status. No other
artefact depends on it.

## 8. Implementation plan

| Step | Owner | Estimate |
|---|---|---|
| Extend `check-generated.mjs` to validate `index.md` against the manifest | docs-maintainer | 1.5 h |
| Regenerate `_generated/index.md` to pass | docs-maintainer | 0.5 h |
| Run the full gate suite | docs-maintainer | 0.25 h |

## 9. Acceptance criteria

- **ACC-UR-20261019-095-1** — Every artefact in `manifest.generated[]` is validated by a gate, or is
  removed from the list with a stated reason.
- **ACC-UR-20261019-095-2** — `_generated/index.md` (if retained as generated) covers every manifest
  document and asset; a deliberately removed row fails the gate.
- **ACC-UR-20261019-095-3** — The gate suite is green with the regenerated file.
