## 2. Requested Changes

1. **Default module icon for every project-wide module.** A default module icon emoji is defined for every module in the project, used **only when the module has no icon asset** (`ui.icon`). It is not a per-module hardcode in one page; it is a project-wide fallback.
2. **Standard modules have separate pages.** Every standard-tier module carries its own page under the dashboard; the **main dashboard page lists the core commands**.
3. **Next/Previous page navigate to the standard module pages.** The Next page button advances from the main page to the first standard module's page (e.g. Hello World with its `hello` command), and Previous page goes back.

---

## 3. Acceptance Criteria

- Every module resolves an icon: its declared `ui.icon` when present, otherwise a project-wide default emoji.
- The main dashboard page lists the core commands only.
- Standard-tier modules each have a page reachable by the Next/Previous page buttons; the first is Hello World showing its command.
- No regressions; the documentation gate suite stays green.
