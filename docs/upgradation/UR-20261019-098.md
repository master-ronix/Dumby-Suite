## 1. Summary

The UR register holds 100 records whose numeric suffix runs 1 … 93 with **index `043` absent**, and
whose suffix scheme is inconsistent (it restarts per day for the first three days, then is globally
continuous). `check-ur.mjs` validates front-matter and path resolution but not sequence continuity,
so the gap is invisible to the suite. This request states the numbering scheme once, disposes of
`043`, and adds a continuity rule.

## 2. Business / engineering justification

UR records are the corpus's provenance anchors; the register's usefulness depends on a reader being
able to trust that the sequence is complete and that a missing number means something. An
unexplained gap invites the question "was a record deleted?", which is exactly the outcome the
corpus's frozen-record discipline exists to prevent. An inconsistent suffix scheme makes IDs hard to
sort and reason about.

## 3. Scope & impact

- **In scope:** `scripts/docs/check-ur.mjs` (add a continuity rule), `upgradation/README.md` (state
  the scheme and dispose of `043`), optionally a note for any future withdrawn record.
- **Out of scope:** renaming existing records (they are frozen; IDs are stable and unique).
- **Audiences affected:** maintainers and auditors reading the register.

## 4. Current state (evidence)

- 100 `UR-*.md` files; indices 1 … 93; **`043` absent on every date**.
- Scheme: `20261008-001…005`, `20261009-001…002`, `20261010-001` (per-day restart), then
  `20261011-001…025`, `20261012-026…089`, `…090`, `…091`, `…092`, `…093` (global-continuous) — so
  `001` appears on four dates.
- `check-ur.mjs` checks front-matter completeness, `kind: ur`, and that cited corpus paths resolve;
  it does not check continuity. Finding DA-5.

## 5. Proposed change

1. State the canonical scheme in `upgradation/README.md`: **global-continuous index from the first
   record**, with the date as the raise date only. (Existing records are not renamed.)
2. Record the disposition of `043` in `upgradation/README.md` — withdrawn / reserved / never raised —
   as a one-line note.
3. Add a rule to `check-ur.mjs`: the set of indices is gapless, **or** every gap has a matching
   entry in a `withdrawn` list in `upgradation/README.md`. Fail otherwise.
4. Note that new records continue from the current maximum (`094` onward), which this audit's URs do.

## 6. Risks & mitigations

| Risk | Likelihood | Mitigation |
|---|---|---|
| Continuity rule fails on the existing `043` gap | High | Land the `043` disposition note in the same change-set |
| A future withdrawal is blocked by the rule | Medium | The rule allows gaps that carry a documented withdrawn entry |
| Renaming temptation breaks frozen provenance | Low | Explicitly out of scope; IDs are stable |

## 7. Rollback / reversal plan

Revert the `check-ur` rule and the README note; the register returns to its prior state. No record
is modified by this request.
