## 1. The corrections (verbatim, formalised)

1. The white-square asset is used as the fallback **logo** for modules that declare no icon; the
   original intent was a **new fallback logo**, with the white square kept as a **decoration** beside
   the slash-command listing on the dashboard's **module-specific page**.
2. Module description and tier labels look messy and vague.
3. Remove the disable/uninstall button; make the **Info** buttons in-line **after each module** in
   the listing, not grouped below the footer.
4. **Move uninstall/disable into the module Info** (the module detail card); keep it **disabled** on
   an uninstalled/disabled marketplace-tier module's card; **generate a new white icon** for it and
   add **no label**.
5. Keep navigation buttons **consistent** with the other pages.
6. Keep the module Info card **hidden (ephemeral) always**.

## 3. Requested changes

- **R1 (1).** A **new fallback logo** asset (`module-fallback-icon.png` → `dumby_module_fallback`,
  a bold white cube) is the fallback for a module that declares no `ui.icon`. The white-square asset
  (`dumby_module`) becomes the **command decoration** beside each command on the dashboard's
  module-specific page (never a logo fallback).
- **R2 (2).** The listing renders each module as a **Section**: its logo, bold name and **title-cased
  tier** on the heading, its description as `-#` subtext.
- **R3 (3).** The per-module **Info** control becomes an in-line Section **accessory** after each
  module; the per-module Uninstall/disable button rows and the instruction line are removed.
- **R4 (4).** The module **detail card** (the Info payload) carries an **icon-only** uninstall/disable
  control (a new bold white trash icon, `dumby_uninstall`, no label). It is **disabled** for a
  core-tier module (never uninstallable) and for an uninstalled/disabled marketplace-tier module.
  Selecting it disables the module for the guild and refreshes the card in place.
- **R5 (5).** The `/modules` navigation row matches the dashboard's: an **icon-only Home** (to the
  dashboard home) plus **Next page** / **Previous page**, using the same schemes (`dumby:nav:` for
  Home, `dumby:act:` with a page segment for paging), with a control disabled at its bound. The
  module list is paginated (`MODULES_PAGE_SIZE`).
- **R6 (6).** The Info control keeps `ack: 'ephemeral'` — the detail card is always private.
