# UR-20261012-061 — One Holder Per Guild

**Freeze status:** Executed — 2026-10-12 (see the `v5.5.66` entry in `upgradation/change-log.md`).

---

## 1. The report

> _"Persona & main bot's modules are shared not synced. If I install a module in main bot the persona
> shows that module installed and listed in its /dashboard /modules /browse /persona everywhere."_

## 2. Why

`/modules`, `/dashboard` and `/browse` filtered by **the guild's** enablement and consulted **no
ownership at all**. The ownership data existed — `guild_persona_bindings` — but those pages never read
it. Only `/persona` was scoped (UR-054).

## 3. The rule, from UR-20261012-059

- **Core** is shared: owned by nobody, visible to every profile.
- **Standard / marketplace** belong to **one** profile in a guild — whoever claimed it first.
- The other profile is **refused** and told who holds it.

## 4. The change

- **One ownership read.** `resolveOwner` is now a `PageDataDeps` dependency, backed by
  `PersonaCommandBindingService.resolveCommandOwner`, memoized per guild+module. `/modules`,
  `/dashboard`, `/browse` and `/persona` all consult it, so they cannot disagree.
- **Every page takes `actingProfileId`** — `'main'` for the main bot, a persona id for a persona. The
  router passes its own identity, so a page reports for the profile that is acting.
- **`/modules` and `/dashboard`** list core plus only what the acting profile holds.
- **`/browse`** lists what the acting profile may install **plus** what another profile holds, marked
  `occupied` with the holder named — in the section and in the dropdown option. A Discord select cannot
  disable a single option, so the fact is stated and the install is what refuses.
- **The install refuses an occupied module** (`PersonaOccupiedError`), and a **persona installing an
  unclaimed module claims it** — the binding is written, which is what makes "first come" real.

## 5. Acceptance criteria

- **ACC-UR-071-1** — a module claimed by a persona is NOT listed as installed for the main bot.
- **ACC-UR-071-2** — core is listed for both.
- **ACC-UR-071-3** — `/browse` marks a module another profile holds as occupied, naming the holder.
- **ACC-UR-071-4** — installing an occupied module is refused; installing an unclaimed one claims it.
- **ACC-UR-071-5** — 94 tests across the affected files pass; typecheck, lint, format clean.

## 6. Recorded

**The data existed; the pages did not ask.** Ownership was already modelled in
`guild_persona_bindings` and already enforced on the command path — the page layer simply had no
concept of "whose page is this". The fix was less about new logic than about giving every page the
identity it was reporting for.
