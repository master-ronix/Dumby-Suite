# ADR-015: Module-Page Footer — `<name> [<id>]` Only; Attribution Stays in the Identity Band

**Status:** Accepted — 09/10/2026
**Deciders:** Dumby Core Engineering — Quixotic Mnemonics
**Supersedes:** — (amends ADR-013's module-footer clause; its other clauses stand)
**Governing sections:** the renderer grammar and module-page sections of the interface reference · the renderer clause of the master-prompt · `contracts/ui-renderer.schema.json`

## Context

ADR-013 fixed the module-page footer as the module name, the module id in brackets, **and** the developer attribution. The program's hardening directive (§5.B.5) requires the footer to show only `<ModuleName> [<module_id>]` — no version, no developer credit, no extra tokens. The two are reconciled without losing attribution, because the developer credit already renders in the identity band (the title block), not only in the footer.

The competing options were:

1. Keep ADR-013's footer unchanged (name, id, attribution).
2. Reduce the footer to `<name> [<id>]` and drop the attribution entirely.
3. Reduce the footer to `<name> [<id>]` and keep the attribution where it already renders — the identity band.

## Decision

The module-page footer renders exactly the module's **display name followed by its id in brackets** — `<display name> [<module id>]` — and nothing else. When a module declares no display name, the title-cased id is used. The developer attribution is **not** repeated in the footer; it remains in the identity band. The footer is omitted entirely on a render that carries no module id (framework chrome rather than a module page). ADR-013's footer clause is amended accordingly; its other clauses — no version on any surface, the dashboard-only page switch, and per-page density — stand unchanged.

## Consequences

- The renderer emits no developer credit in the footer; the footer is the name and id alone.
- Attribution is carried once, in the identity band.
- The footer grammar is fixed as `<name> [<id>]`; no version and no extra tokens appear in it.
- ADR-013 is retained as the historical record of the grammar it fixed; this ADR amends one clause of it, as ADR-013 itself superseded ADR-009.
- **Invariant:** a module page's footer is `<name> [<id>]` and nothing else; the developer attribution lives in the identity band.
