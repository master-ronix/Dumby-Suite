# Getting started

1. Read `blueprint/` to see how the system fits together, then `documentation/` for what each part is.
2. Operators: the Core Command Surface (`/dashboard` home) is your entry point — see [features/core-command-surface](../features/core-command-surface.md).
3. Developers: build a module against the manifest contract — see [building-a-module](building-a-module.md).
4. Agents: start at `prompts/entry.md`, load only the `spec/<dept>/` you need + `contracts/`.
