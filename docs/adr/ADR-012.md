# ADR-012: Official Accent Colour — Amber #FFCA6D, with Per-Module Accents

**Status:** Accepted — 08/10/2026
**Deciders:** Dumby Core Engineering — Quixotic Mnemonics
**Supersedes:** ADR-010 — the single non-configurable blurple accent.
**Governing sections:** the renderer accent and identity sections of the interface reference · the renderer clause of the master-prompt · `contracts/ui-renderer.schema.json`

## Context

ADR-010 fixed one accent — blurple `#5865F2` — as a single, non-configurable value, stated that modules do not set their own accent, and recorded that changing it requires a superseding ADR. The program now requires a different identity: the project's actual accent is amber `#FFCA6D`, and each module is to carry its own accent on its own pages, falling back to amber when it declares none. The change is deliberate and product-level, so it is recorded here as the superseding decision ADR-010 anticipated.

The competing options were:

1. Keep blurple as the single accent.
2. Replace blurple with amber as the single accent, still non-configurable.
3. Replace blurple with amber as the framework default and permit a declared per-module accent, with amber as the fallback.

## Decision

Amber `#FFCA6D` is the official accent colour and the framework default. The single-accent rule of ADR-010 is superseded: a module MAY declare its own accent for its own renderer-issued pages, through the module contract's UI fields, and when it declares none the amber default applies. Framework chrome — dividers, footer rules, the buffer indicator, and the formal notice marker — renders in amber unless the page supplies its own accent. No blurple value remains on any current surface or in any current specification.

## Consequences

- The renderer's accent constant is amber; the contract's accent field is amber; current specs and the master-prompt state amber.
- A module declares its accent and banner through its manifest UI fields; absent a declaration, the default banner and amber apply.
- Tests that asserted the blurple token assert amber instead.
- ADR-010 is superseded and retained as the historical record of the decision this one reverses; it is not rewritten to erase its own context.
- **Invariant:** exactly one framework default accent (amber `#FFCA6D`); a page accent is a declared, per-module choice, never an undeclared override.
