# ADR-014: Module Icons as Custom Emoji; Developer Attribution from the Account Registry

**Status:** Accepted — 08/10/2026 (attribution clause superseded by ADR-015)
**Deciders:** Dumby Core Engineering — Quixotic Mnemonics
**Supersedes:** — (refines ADR-012's `ui.icon` field and ADR-013's attribution slot)
**Superseded by:** ADR-015 — the attribution clause only; the icon decision stands.
**Governing sections:** the renderer grammar · the dashboard and module-icon sections of the interface reference · `contracts/ui-renderer.schema.json`

## Context

Two surfaces were under-specified. First, a module's logo icon: the manifest carries a `ui.icon` string, but the mechanism that renders it beside a name, and the fallback when a module declares none, were not fixed. Second, the developer attribution: the framework rendered a static organisation name, while the platform issues each developer a registered username through the account registry (the credentials service, coordinated with Swastik and the development portal).

The competing options were:

1. Keep emoji defaults per module, keyed in the framework.
2. Render icons as custom Discord emoji — the manifest names the emoji, the framework supplies a bundled default white icon when a module names none.
3. Keep the developer attribution as a static name.

## Decision

**Icons.** A module's icon is a **custom Discord emoji**. The manifest's `ui.icon` names the emoji; a module that names none uses the framework's **default white icon**, bundled at `apps/main/assets/default-module-icon.png` and uploaded once as an application emoji at bootstrap. An emoji id is only known at runtime, so the icon resolves through a registry populated at boot; until then a unicode fallback applies so a page never renders without an icon. The per-module emoji hardcode is removed.

**Attribution.** The developer attribution is the developer's **platform-registered username**, resolved from the account registry by the manifest's `devId`. A `devId` that is not registered resolves to nothing and the caller falls back to the declared developer rather than inventing a name. The static organisation name is no longer the attribution source.

**Placement.** The page's action controls sit below the footer, separated by a divider; a dashboard page carries no in-content heading; and only the main dashboard page shows each command's module icon — a module-specific page shows none.
